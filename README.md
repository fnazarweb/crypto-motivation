# Crypto Motivation

[🚀 Live Demo](https://fnazarweb.github.io/crypto-motivation/)

## Features
- 🎯 Generate random motivational posts
- 💾 Save posts to Google Sheets
- ₿ Live BTC/USDT price
- 📈 Price trend indicator
- 🔌 WebSocket connection to WhiteBIT
- 🔄 Automatic WebSocket reconnection
- 🌐 Deployed with GitHub Pages

## Technologies
- HTML5
- CSS3
- JavaScript
- Fetch API
- WebSocket API
- Google Apps Script
- Google Sheets
- WhiteBIT API
